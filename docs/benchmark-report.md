## Known blind spots (honest limitations)

- `image_blindspot`: 0% detection in this battery. In-place encryption of already-high-entropy media (images, video) without a rename leaves entropy within the file type's normal range — the encrypted payload is indistinguishable from native compressed content by entropy alone. Candidates for future signals: magic-byte validation, partial-encryption (front) detection, and size anomalies.
